## Public summary and integrity

dashboard/dist/demo-data.json is generated by tools/export_demo.py from the
hash-pinned report, its 72-file evidence inventory, approved contract and actual
patches. It publishes only allowlisted classifications, finite observations,
counts, diff excerpts, hashes and limitations. No authorization identities,
review minutes/notes, raw logs, absolute paths or complete snapshots are included.
The browser reads this file at runtime and checks its SHA-256 against integrity.json,
then validates presentation consistency. Missing, changed or malformed data
displays EVIDENCE UNAVAILABLE; there is no successful fallback result.

The summary checksum is not an authenticated signature. Altering the app and
manifest together is outside its presentation check. The original report hash
identifies withheld local evidence and does not let a public clone independently
reconstruct the run. This dashboard is a replay, not live collection, a new approval
or remote execution attestation. The summary export is not a new trusted verifier.
