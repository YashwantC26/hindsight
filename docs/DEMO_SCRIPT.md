# 90-second recording script

Start the static server, open the dashboard at laptop width, keep R selected and
close the expandable details. This is a replay of retained results, not a live
execution or a new authorization. Avoid showing private terminals, paths or ledgers.

| Time | Show | Say |
| --- | --- | --- |
| 0–12s | Title and workflow | “HINDSIGHT is developer-controlled regression memory for AI-assisted coding. A bug can be fixed, then brought back by a later edit. We preserve a reviewed behavioral obligation so the next patch can be checked against it.” |
| 12–25s | Seeded disclosure, then three cards | “This regression is deliberately seeded for demonstration. We are not claiming autonomous discovery of a naturally occurring AI-generated bug. The known-good baseline passed, the seeded change was detected, and the benign control passed.” |
| 25–45s | R patch and four failed pairs | “This one early return skips removing an old live value when its replacement is expired. At the expiry boundary, and before it, C1 requires membership to be false. C2 requires lookup to raise KeyError. Instead the key remains present and reads the stale value, five. These are four distinct scenario-and-claim violations.” |
| 45–57s | Click B, then N, then R | “The same approved check runs against all three source trees. The baseline and docstring-only control each passed all 36 assertions. R passed the survivor and valid-replacement controls, but repeated the four failures three times.” |
| 57–70s | Expand Execution & stability | “Nine fresh processes, three stable repetitions per candidate. The retained run contains 108 assertions and 144 setup checks. Errors, unstable runs and incomplete evidence cannot be reported as a regression.” |
| 70–83s | Report hash and Human boundaries & provenance | “These results come from a retained, independently reviewed local run. This public view loads a derived summary with a checksum and the original report hash. Raw evidence and approval identities stay private. Contract review, activation and future execution are separate human decisions.” |
| 83–90s | Return to R comparison | “This MVP demonstrates one reviewed regression memory end to end. It does not promise universal correctness or autonomous bug discovery. The useful outcome is a concrete signal a developer can inspect before accepting a change.” |

Before recording, test the candidate buttons once. Use a clean browser window and
record the dashboard, not the original evidence directory. No extra execution is needed.
